# Как опубликовать AI Security Monitor как сайт

## 1. Загрузите проект в GitHub

Загрузите **содержимое этой папки** в корень репозитория. В главной папке репозитория должны сразу находиться `app.py`, `requirements.txt`, `config.py`, папки `src`, `models`, `data` и `outputs`.

## 2. Подключите Streamlit Cloud

1. Откройте https://share.streamlit.io/ и войдите через GitHub.
2. Нажмите **Create app**.
3. Выберите ваш репозиторий и ветку `main`.
4. В поле **Main file path** укажите `app.py`.
5. Нажмите **Deploy** и подождите, пока установятся библиотеки.

После публикации Streamlit покажет ссылку на сайт.

## 3. Запуск на компьютере

В терминале из папки проекта выполните:

```bash
pip install -r requirements.txt
streamlit run app.py
```

## Что умеет сайт

- Показывает обзор событий, графики и журнал предупреждений.
- Анализирует CSV с сетевыми потоками с помощью Isolation Forest и Random Forest.
- Классифицирует HTTP-запросы как Normal, SQL Injection или XSS.
- Позволяет загрузить CSV, посмотреть результат и скачать его.
- Показывает метрики моделей и матрицы ошибок.

**Важно:** включённые данные синтетические, а результаты — только прогнозы модели, не подтверждённые инциденты. Не загружайте на публичный сайт реальные журналы, пароли, токены или другие чувствительные данные.
